# Sales Performance Analysis & Interactive Dashboard

**Tools:** Python (Pandas, Matplotlib), SQL (SQLite), Excel (formulas, charts), Tableau

End-to-end analysis of 6,000+ retail orders (Jan 2024 - Dec 2025) across 4 regions, 3 product categories and 24 products: from raw, messy data to an interactive dashboard for business decisions.

> **Data note:** The dataset is synthetic and generated by `01_generate_raw_data.py` with realistic data-quality problems injected (duplicates, mixed date formats, inconsistent labels, missing values, outliers). To use real data, drop a retail sales CSV (e.g. Kaggle "Superstore") into `data/raw/` and adjust the column names in `02_clean_and_analyze.py`.

## Pipeline
| Step | File | What it does |
|---|---|---|
| 1 | `01_generate_raw_data.py` | Builds raw sales, product and region tables (6,150 messy rows) |
| 2 | `02_clean_and_analyze.py` | Cleans data with Pandas, logs every fix, computes KPIs, saves charts |
| 3 | `03_run_sql.py` + `sql/analysis_queries.sql` | Loads into SQLite, runs 12 queries (joins, GROUP BY, window functions, CTEs, subqueries) |
| 4 | `04_build_excel.py` | Builds `Sales_Analysis.xlsx`: live SUMIFS / INDEX-MATCH / VLOOKUP formulas, KPI sheet, 5 charts |
| 5 | `TABLEAU_GUIDE.md` | Steps to build the dashboard from `data/clean/tableau_sales.csv` |

Run everything: `pip install pandas numpy matplotlib openpyxl`, then run scripts 01 to 04 in order.

## Data cleaning (see `data/clean/data_quality_log.txt`)
- Removed 150 exact duplicate rows (6,150 to 6,000)
- Standardised 16 inconsistent region spellings/cases to 4 valid values; trimmed and title-cased segment and state
- Parsed 3 mixed date formats into one datetime column
- Fixed 10 negative quantities and flagged 8 impossible discounts (>100%)
- Detected 7 sales outliers (>5x expected) and recomputed them from price x quantity
- Filled 60 missing sales and 80 missing profit values from the product master; imputed other fields with documented rules
- Result: 0 null values; added year, quarter, month and profit-margin features

## Key insights
1. **Regional concentration:** West contributes about 33% of sales; East only about 17% - the biggest growth opportunity.
2. **Seasonality:** Q4 is the peak quarter; Q4 2025 sales grew about 29% YoY, while Q2 declined about 9%.
3. **Discounts destroy margin:** margin falls from about 30% (no discount) to about 0.5% at 30% discount.
4. **Category mix:** Technology brings about 87% of revenue at 21% margin; Furniture earns 34% margin on about 10% of revenue.
5. **Margin leaks:** Smartphone S, Smartphone Lite and Laptop Air 13 sell well but earn margins around 7-11%, versus a company average of 22.5%.

## Recommendations
- Cap discounts at 20% and require approval above it
- Push higher-margin Furniture bundles with Technology purchases
- Run targeted campaigns in East; replicate West's best-selling product mix
- Stock up and plan promotions ahead of Q4
