Sales Data Analyzer

A browser-native analytics tool built for data analyst portfolios

🔒 Privacy First

All processing happens entirely in your browser using WebAssembly. No data is ever sent to any server.

🧹 Intelligent Cleaning

Automatically detects and fixes duplicate rows, inconsistent text casing, mixed date formats, negative quantities, missing values, and statistical outliers.

📈 Auto Dashboard

Generates KPI cards, six interactive charts, and auto-written key insights from your cleaned data. Filter by date, region, category, and segment.

🗄️ SQL Playground

Run full ANSI SQL (with window functions, CTEs, subqueries) on your data using SQLite WASM. Seven example queries included.

🛠️ Tech Stack

HTML5 + CSS3 Vanilla JavaScript PapaParse v5 SheetJS (xlsx) sql.js (SQLite WASM) Chart.js v4 CodeMirror 5 html2canvas
